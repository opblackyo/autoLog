# AutoLog 上班時段快填

在學校原本的 Time Log 網站右下角加入「快速填寫」按鈕的 Chrome／Edge 擴充功能。不需要另外輸入或儲存密碼；使用原網站已登入的帳號。

## 安裝

1. 開啟 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打開「開發人員模式」，點「載入未封裝項目」。
3. 選取本專案的 **extension** 資料夾（內有 manifest.json）。若使用 ZIP，先解壓縮再選該資料夾。
4. 連上學校網路／VPN，開啟 [Time Log](http://140.124.181.95:30201/)，自行登入，再重新整理一次。
5. 點右下角「快速填寫」。第一次連線會確認帳號並讀取你所屬的 Team 與 Activity Type。

## 每週使用

1. 選週次。日期選該週任一天即可，會自動換算成星期一到星期日。
2. 預設標題 **MOB**、組別 **CrossFunctionalFrontEnd**、類型 **LabProject**；只會選擇實際存在於你帳號的選項，也可改成其他組別與類型。
3. 依實際出勤勾選。請假可取消單筆，或按「整天請假」的星期按鈕。每列可改日期／時間，亦可加入或移除時段。
4. 點「檢查紀錄並預覽」，確認新增明細與總時數，再按「確認送出」。
5. 每筆新增後會再讀取紀錄確認。回到學校左側 **Personal → History**，設定日期範圍查閱；原頁沒有更新時重新整理。

## 介面操作

- 上方「填寫設定與備註」預設顯示目前設定摘要，點開即可改標題、組別、類型與備註；缺少必要設定時會自動展開。
- 勾選區放大為至少 44px 高，也可以點每列的狀態或空白處切換；點日期、時間或移除按鈕時不會誤切換。
- 清單完整展開，只捲動面板的主內容，底部總時數與操作始終可見。預覽時底部會改為「返回修改／確認送出」。
- 窄螢幕將每筆時段改成直向排列，不必左右滑動。整天取消與範本管理放在清單下方，讓勾選優先顯示；範本選單可從「套用或管理時程範本」展開。

固定時程共六筆、十小時：

| 星期 | 時段 | 小時 |
|---|---|---:|
| 二 | 10:00–12:00、13:00–14:00 | 3 |
| 三 | 14:00–15:00 | 1 |
| 四 | 10:00–12:00、13:00–15:00 | 4 |
| 五 | 13:00–15:00 | 2 |

**12:00 是中午 12 PM，13:00 是下午 1 點。** 所有日期與驗證採台北時間。今天與過去的時段可填寫，今天即使尚未開始或結束也可填寫；明天以後不能勾選或送出。因此週五以前查看本週時，勾選總時數可能少於十小時。既有草稿會保留請假勾選，需要補選今天的時段時可按「勾選可填時段」。

## 自訂與範本

- 調整時段後展開「套用或管理時程範本」，輸入名稱，按「儲存時程為範本」。同名會覆寫。範本儲存所有列出的固定時段，不儲存當週請假勾選，也不儲存 Team／標題。
- 刪除時，在相同區塊的「刪除自訂範本」選擇名稱，按「刪除範本」。選擇刪除對象不會套用範本，當週時段、勾選、其他草稿與設定都會保留。誤刪可在面板關閉前按「復原刪除」復原最近刪除的一個範本；內建「我的固定 10 小時」不能刪除。
- 從「套用範本」選取名稱即可重新產生當週日期；會取代當週目前時段與勾選。「我的固定 10 小時」可還原原始時程。
- 當週時段、勾選、範本與上次組別設定按帳號存於此瀏覽器的網站本機儲存區。換週會保留各週草稿。清除網站資料會移除這些設定。

## 送出與錯誤處理

- 每次送出前查歷史紀錄；與任何類型紀錄相同或重疊的時段都略過。本次批次內重疊也會擋下，相接的時段可分別填寫。
- 每筆送出前再查一次。寫入後確認相同時間、標題、類型與組別存在，才標記成功。
- 任何讀取／寫入／查核失敗都停止剩餘批次，不會自動重送。狀態不明時，先查學校 History，再按「檢查紀錄並預覽」。
- 同一瀏覽器的擴充功能會拒絕同帳號同時送出的另一批。學校 API 沒有可用的冪等或交易介面；不同裝置或原頁同時手動新增，仍可能競爭。批次進行中請勿在其他裝置同時新增。
- 目前依學校公開前端程式確認 API 格式，實際登入與正式寫入仍需在你的帳號驗證。網站更改 API 或回傳格式時會報錯停止。

## 本機示範與開發

需 Node.js 20 以上，無其他套件依賴。

```sh
npm test
npm run preview
```

若本機 npm 損壞或沒有安裝 npm，也可直接執行 `node --test tests/*.test.cjs` 與 `node scripts/preview.cjs`。Windows 打包可直接執行 `powershell -NoProfile -File scripts/package.ps1`。

開啟 [本機互動示範](http://localhost:4173)。示範使用記憶體中的假資料，不會連上學校網站，重新整理後模擬歷史紀錄會清空。可切換到過去週次測試完整六筆送出與重複偵測。

```sh
npm run package
```

產生 `dist/autolog-extension.zip`。擴充功能不需要打包編譯，更新程式後在擴充功能頁按「重新載入」，再重新整理學校網站。

## 實作與權限

`extension/core.js` 負責台北時間、時程、驗證與 payload；`content.js` 以 Shadow DOM 隔離面板樣式；`background.js` 呼叫學校原有的 API。擴充功能僅允許學校 IP，並且只在 `30201` 的 Time Log 頁啟用；背景程式也查驗訊息來源。Chrome 的主機權限格式無法限制連接埠，因此 manifest 宣告該 IP 後，由程式限制實際用途。沒有外部分析、排程自動送出或第三方服務；登入 token 僅從原網站取用並送往學校 profile API，不寫入範本、不輸出到日誌。
